# APACS Monitor

WPF-приложение на C#/.NET для отдельного мониторинга событий APACS Apollo 3000 через SQL Server.

## Назначение

Приложение не изменяет данные APACS. На первом этапе оно только читает `dbo.TAPCSYSEVENTSCOMMON`.

Текущая версия умеет:

- настраивать SQL Server и базу данных через отдельное окно;
- Windows Authentication или SQL Server Authentication;
- проверять подключение;
- сохранять сервер, базу и имя пользователя в `appsettings.json`;
- не сохранять пароль в файл;
- показывать последние 100 событий;
- автоматически обновлять список каждые 2 секунды;
- выполнять ручное обновление.

## Требования

- Windows 10/11 x64;
- Visual Studio 2026 с workload `.NET desktop development`;
- .NET 10 SDK;
- SQL Server с доступной базой APACS.

## Запуск

Открыть `ApacsMonitor.sln` в Visual Studio и выполнить запуск проекта.

Для локальной разработки по умолчанию используется:

- Server: `localhost\\DEV`
- Database: `apacs3000rus`
- Authentication: SQL Server
- User: `sa`

Пароль вводится при запуске и остаётся только в памяти приложения.

## Важно

Для production не использовать `sa`. Следующим этапом будет отдельная SQL-учётная запись с правами только на чтение необходимых таблиц.

Также пока не следует считать поля `FNUMEVTYPE`, `FSAINITOBJ*` и `FSEK*` окончательно расшифрованными: их смысл нужно сопоставить с реальными событиями APACS перед построением бизнес-логики проходов.
